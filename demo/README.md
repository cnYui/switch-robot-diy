# 装配与操作演示 V0.2

assembly_and_operation.mp4 是 18 秒、1120×840、12 fps 的演示视频，包含装配、合盖、按上端、回中、按下端、回中的过程。assembly_and_operation.gif 是可循环预览；assembled_annotated.png 是有中文标注的完整装配图。

switch_robot_assembled_v02.blend 保存了演示场景、摄像机和关键帧。场景名为 `86 Robot - assembled and operating V0.2`，时间轴 1–216，保存时停在第 60 帧的完整装配状态。打开后可播放时间轴查看动作。V0.1 原始场景也保留在文件内。

按用户纠正，翘板开关采用 +3.5° 和 -3.5° 两个保持状态，机械臂收回时不会把翘板带回水平。切换瞬间有短暂经过中间位置的动画，代表翘板从一侧翻到另一侧。视频右上的侧视图放大了倾角，帮助识别两端的高低关系，不是尺寸图。

为避免中立位置压住翘起的一侧，本演示副本把按压臂末端下面的几何缩短约 1.5 mm，其他主体轴线保持原位置。演示按压角度约 ±11.4°。这些是几何说明参数，不是经过实物校准的舵机控制角度；它们没有替换 V0.1 的生产 STL，也未验证接触变形、受力或全部动态间隙。

本次在已有模型上补充了舵盘连接示意、绑带、螺钉、连接线、盒盖的闭合位置和装配动作。电子板与主控仍为外形占位，视频中的“开灯/关灯指令”是操作说明，不代表已经实现网络控制。控制盒如何在墙上固定、电源线如何接到实际电源以及实物安装仍需后续设计。

动画关键帧已检查，MP4 已确认 H.264 编码、216 帧、18 秒。animation_contact_sheet.jpg 保存装配和两侧动作的关键画面。生成脚本分别为 build_demo_mcp.py（Blender 场景构建）与 finish_demo.py（中文标注和编码）。
