# PCB / 盒体尺寸审查与 V0.3 修正

检查结论：原始 V0.1 盒体（也用于 V0.2 动画）无法无干涉容纳矩形 PCB。PCB 板框与四个安装孔的设计一致，但盒盖四根螺柱落在 PCB 矩形四角，产生约 38.48 mm³ 的实体交叠。先前的外观装配图不能作为装配验证。

板框和安装孔取自 electronics/carrier_v01.epcb 的实际图元：60×40 mm、四个直径 3.2 mm 的非金属化孔，孔中心为 (4,4)、(56,4)、(56,36)、(4,36) mm。PCB 厚度按 Blender 中 1.6 mm 假设，不是已收到实物的测量。

V0.3 盒体另存，没有覆盖原模型、演示视频或 PCB。外尺寸改为 76×56×30 mm，平面内腔 72×52 mm，壁厚 2 mm。板底和安装孔中心保持不变。盒盖柱中心移到盒体中心的 ±34、±24 mm，半径 3 mm；柱边到 PCB 最近角点的几何净距约 2.66 mm。PCB 板边距侧壁各 6 mm。

原盒体 PCB 板面到闭合盒盖下表面的空间为约 13.5 mm；修正版增加到 21.5 mm。PCB 板底到内底面的空间约 4.9 mm，用于螺柱和焊点。实际元件最高点、插接高度及线材仍需校核；21.5 mm 是可用空间，不是已经通过的元件高度。

Blender 精确布尔检查结果：修正版 PCB 与盒体交叠体积 0 mm³，PCB 与闭合位置的盒盖交叠体积 0 mm³。两个打印件的非流形边数均为 0。这些检查只覆盖已建模的裸板与塑料件，不包括打印收缩、螺钉拧入、板弯曲或完整元器件装配。

enclosure_fit_v03.blend 为原生工程；其中盒盖为便于观察而移开，布尔检查是在闭合位置执行后才移开。case_v03_pcb_fit.png 是该观察视图。V03_PRINT_gateway_case_76x56x30.stl 和 V03_PRINT_gateway_lid_76x56.stl 为毫米单位的独立零件。

尚未通过整机尺寸审查。电脑连接的主控型号仍未识别，原蓝色 26×20×5 mm 主控模型只是占位；不能据此认定实物能放下。F1、C1、C2、接插件、端子、线缆及插头没有全部选定具体料号，封装高度和插拔空间均未验证。原 C1 / C2 的中心距离约 4.67 mm，若 C1 使用直径 10 mm 的立式电容，C2 的焊盘/本体区域可能冲突，需要重排并按实物封装重新做电路及机械检查。

开口仍是线缆穿孔示意，不是与已采购 USB、接线端子或插头匹配的最终接口。额外空间也没有为未知主控设计固定柱。不要因为本次裸板避让通过，就把 PCB 草稿、演示图或修正版盒体当成已经可投产的整机。
